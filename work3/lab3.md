ДОМАШНЯЯ РАБОТА. КЛАССЫ, СТРУКТУРЫ И ПЕРЕЧИСЛЕНИЯ

Работайте по этапам. Сначала добейтесь результата на одном объекте, затем переходите к массиву. Никакой графический интерфейс не нужен. Имена и параметры ниже — учебная модель, не реальные биологические данные.

ЗАДАНИЕ 1. ЗООПАРК, КОТОРЫЙ ЖИВЁТ САМ

Этап 1. Создайте базовый класс Animal.
Свойства: name: String, age: Int = 0, daysWithoutFood: Int = 0.
Методы: makeSound() -> String, eat(), growOlder().
eat() сбрасывает daysWithoutFood в 0.
growOlder() увеличивает age и daysWithoutFood на 1.
Добавьте вычисляемое свойство description с именем, возрастом и днями без еды.
Создайте одно животное, вызовите методы вручную и проверьте значения.

Этап 2. Создайте Rabbit, Parrot и Turtle — наследников Animal.
Переопределите makeSound(): «Фыр-фыр», «Привет!», «Тишина — тоже ответ».
В Animal добавьте вычисляемое свойство maxAge, возвращающее 10.
Переопределите его у Rabbit на 12, Parrot на 15, Turtle на 20.
Числа означают условные дни симуляции.
Добавьте ещё два своих вида с другими звуками и сроками жизни.

Этап 3. Создайте класс Zoo с массивом [Animal].
Добавьте методы add(animal:) и showAnimals().
Создайте 10 животных разных видов, добавьте в зоопарк и выведите описание каждого вместе с его звуком. Массив должен быть общим для всех видов, а не отдельным для каждого подкласса.

Этап 4. Научите животных умирать в симуляции.
Добавьте в Animal вычисляемое свойство isAlive: Bool.
Животное живо, пока age < maxAge и daysWithoutFood < 3.
Смерть наступает, когда возраст достиг maxAge ИЛИ прошло 3 дня без еды.
Проверьте одного зверя вручную: после трёх growOlder() без eat() он неживой. Если покормить перед третьим днём, он должен остаться живым при допустимом возрасте.
Смерть — исключение из популяции; deinit для этого не нужен.

Этап 5. Реализуйте один день: Zoo.liveOneDay().
Сначала зафиксируйте участников: let todayAnimals = animals.
Для каждого выберите Int.random(in: 1...2).
Если выпало 1 — вызовите eat(), если 2 — напечатайте, что зверь отдыхает.
После выбранного действия вызовите growOlder().
Поэтому в конце дня после еды daysWithoutFood будет равен 1.
Когда цикл завершён, удалите неживых из основного массива: animals.removeAll { !$0.isAlive }.
Выведите число оставшихся животных.
Запустите 10 дней обычным циклом. Если животных не осталось, завершите раньше.
Сначала проверьте один день без random: задайте действие числом вручную.

Этап 6. Добавьте рождения.
В Animal добавьте метод makeBaby() -> Animal, создающий Animal с именем «Малыш».
У каждого наследника переопределите его: Rabbit создаёт Rabbit, Parrot — Parrot и так далее. У детёныша возраст и daysWithoutFood равны 0.
Расширьте случайное действие до 1...3: 3 — попытка рождения.
В нашей упрощённой модели достаточно одного родителя, искать пару не нужно.
Родитель может создать одного малыша за свой ход, только если age >= 2 и daysWithoutFood <= 1 на момент действия.
Храните новых животных в отдельном массиве babies, а не добавляйте в animals внутри обхода.
После действий все участники todayAnimals стареют; удалите умерших, затем добавьте babies. Малыши в день рождения не действуют и не стареют.
Чтобы ограничить рост, перед рождением проверяйте todayAnimals.count + babies.count < 30. Свободные места после смерти можно использовать со следующего дня.
Родитель, умерший в конце дня, не отменяет уже состоявшееся рождение.

Этап 7. Итоговая демонстрация.
Запустите максимум 30 дней без ввода пользователя.
Печатайте номер дня, выбранные действия, рождения, имена умерших и количество оставшихся.
В конце покажите общее число рождений, смертей и оставшихся животных.
Проверьте: начальное количество + рождения - смерти = осталось.
Зоопарк может вымереть: вечная жизнь не требуется.

Сдайте Swift-код и короткий пример вывода.
Обязательные проверки: животное ест; умирает на третьем дне без еды; умирает при age == maxAge; незрелый зверь не рождает; малыш имеет правильный класс; малыш не стареет в день рождения; ограничение 30 соблюдается; пустой зоопарк завершает работу.
Не усложняйте модель полом, охотой, болезнями и вольерами.
