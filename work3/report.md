# Лабораторная работа № 3 — зоопарк на Swift

## Сборка и запуск

На macOS нужны Xcode или Command Line Tools с поддержкой Swift 6.

```sh
./build_manual.sh
```

Скрипт устроен аналогично скриптам запуска предыдущих работ: сначала собирает динамическую библиотеку и модуль `ZooKit`, затем исполняемый файл `ZooLab`, связывает их и запускает программу. Результат сохраняется в `.manual-build/`.

Если установлен полный Xcode, скрипт использует его компилятор и SDK. Явно заданный `DEVELOPER_DIR` имеет приоритет. Альтернативный запуск через Swift Package Manager:

```sh
swift run ZooLab
```

## Структура

- `Sources/ZooKit/Animal.swift` — базовый класс `Animal` и наследники `Rabbit`, `Parrot`, `Turtle`, `Cat`, `Dog`. Кошка и собака - два дополнительных вида с условными сроками жизни 14 и 16 дней.
- `Sources/ZooKit/Zoo.swift` — общий массив `[Animal]`, действия, рождения, удаление умерших, ограничение популяции и итоговая статистика.
- `Sources/ZooLab/main.swift` — ручные проверки одного животного, один день с заданным действием и основная случайная симуляция с 10 животными, максимум на 30 дней.

Возраст измеряется условными днями симуляции. Все начальные животные имеют возраст 0. Основная демонстрация использует случайное действие от 1 до 3 и максимум 30 дней.

## Порядок одного дня

1. Зафиксировать участников: `let todayAnimals = animals`.
2. Для каждого выбрать действие: `1` — еда, `2` — отдых, `3` — попытка рождения.
3. Рождение возможно при `age >= 2`, `daysWithoutFood <= 1` и `todayAnimals.count + babies.count < 30`. Детёныши в день рождения хранятся отдельно.
4. Увеличить возраст и дни без еды всех участников на 1. Поэтому после еды в конце дня `daysWithoutFood == 1`.
5. Вывести имена умерших и удалить их: смерть наступает при `age >= maxAge` или `daysWithoutFood >= 3`.
6. Добавить малышей. Они имеют правильный класс, нулевые возраст и голод, в день рождения не действуют и не стареют.

Места умерших доступны для рождения только со следующего дня. Если родитель умер в конце дня, его уже родившийся малыш остаётся. При пустом зоопарке симуляция останавливается. В итогах проверяется баланс: начальное количество + рождения − смерти = осталось.

## Короткий пример вывода

Фрагменты фактического запуска, промежуточные строки опущены.

```text
Проверка одного животного
Зверёк: возраст — 1, дней без еды — 1
После еды: Зверёк: возраст — 1, дней без еды — 0
После трёх дней без еды жив: false
Если покормить перед третьим днём, жив: true

Один день с заданным вручную действием

День 1
Тестовая черепаха: ест
Осталось животных: 1

...

День 24
Малыш: отдыхает
Умер: Малыш
Осталось животных: 0
Зоопарк пуст. Симуляция завершена досрочно.

Итоги: рождений — 18, смертей — 28, осталось — 0
Баланс: 10 + 18 - 28 = 0
```
