# Лабораторная работа №2

## Описание

Все решения находятся в `main.swift`. Каждое задание отделено комментарием с номером, результаты выводятся в консоль.

1. **Строки и интерполяция.** Фраза `Swift makes sense!` собрана из двух строковых констант и выведена двумя способами: с помощью оператора `+` и строковой интерполяции.

2. **Возраст и количество прожитых дней.** На основании текущего возраста вычислены возраст через семь лет и приблизительное количество дней с рождения к этому моменту. Использовано среднее количество дней в году `365.2425`; результат хранится в `Float`, а при выводе преобразуется в `Int`. Возраст можно передать аргументом командной строки; допустимый диапазон - от 0 до 150 лет.

3. **Типы `Float` и `Double`.** Числа `7.25` и `18.6` сложены двумя способами: с преобразованием результата в `Double` после сложения и с преобразованием каждого операнда до сложения. Результаты выведены и сравнены, в комментариях объяснено влияние точности типов: для выбранных операндов суммы совпадают, хотя исходное число `18.6` уже округляется при сохранении в `Float`.

4. **Прямоугольный треугольник.** Для катетов `9.0` и `12.0` вычислены гипотенуза по теореме Пифагора с использованием `sqrt`, площадь и периметр. Получены значения 15, 54 и 36 соответственно, функция `pow` не используется.

5. **Целочисленное деление.** Для распределения 17 элементов по 6 коробкам с помощью `/` и `%` вычислены целая часть и остаток. В каждую коробку попадает 2 элемента, остаётся 5. Результат также выведен как смешанное число: `17 / 6 = 2 5/6`.

6. **Вычисления с датой без `Date`.** Только арифметическими операциями рассчитан период с 01.01.2006 до 17.09.2026. По условию месяц принят равным 30 дням, год - 360 дням. Получены 20 полных лет, 248 полных месяцев, 7456 дней и 644198400 секунд за весь период. `Date`, `Calendar` и условные операторы в расчёте не используются.

7. **Определение квартала.** Функция `quarterDescription(for:)` определяет квартал по номеру месяца через `if / else if / else`. Для сентября выводится `III квартал`. Значения вне диапазона `1...12` отклоняются условием `month < 1 || month > 12`.

8. **Косинус и округление.** Вычислен `cos(2.0)`, где аргумент задан в радианах. Результат выведен с точностью до четырёх знаков после запятой двумя способами: арифметическим округлением через `round` и форматированием через `String(format:)`. В обоих случаях выводится −0.4161.

9. **Именованный кортеж.** Создан кортеж с моделью устройства `iPhone 15`, годом выпуска `2023` и объёмом памяти `128` ГБ. Его элементы выведены отдельно и одной строкой с обращением по именам `model`, `releaseYear` и `storage`.

10. **Доступ в лабораторию.** Составлено выражение `hasStudentID && (isInstructor || hasScheduledClass && safetyBriefingPassed)`. Идентификатор обязателен для всех, студенту дополнительно нужны занятие и инструктаж, а преподавателю - нет. Проверены шесть комбинаций, включая отказ преподавателю без идентификатора.

11. **Поиск ошибки в условии.** Объяснено, почему проверка `month < 1 && month > 12` всегда ложна: число не может одновременно нарушать обе границы. В исправленной функции используется `||`. Проверены месяцы `-2`, `-1`, `0`, `1`, `4`, `9`, `12`, `13`, `15` и `27`.

12. **Число Фибоначчи.** Вычислено и полностью выведено 4250-е число Фибоначчи, содержащее 888 цифр. Поскольку результат не помещается в `Int`, использованы массивы десятичных цифр числа и сложение с переносом. Итог сохраняется в строковой константе `fibonacci4250` без потери точности.

## Сборка и запуск на macOS

Нужны Xcode или Command Line Tools с поддержкой Swift 6.

```sh
./build_manual.sh
```

Без аргументов используется возраст 20 лет. Чтобы указать свой возраст:

```sh
./build_manual.sh 21
```

Скрипт, вызывает `xcrun swiftc` и запускает собранную программу. Аргументы передаются программе. Пути определяются относительно скрипта, поэтому запуск возможен из любого каталога. Результаты сборки находятся в `.manual-build/`.

По умолчанию используется отладочная сборка. Оптимизированная сборка:

```sh
CONFIGURATION=release ./build_manual.sh 21
```
